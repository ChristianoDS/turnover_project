### Passo 2: Planejar o Processo

- Etapa 00: Cálculo do ROI do projeto
    - Definição da Métrica de Negócio
    - Definição da Métrica Técnica
    - Pesquisa de Mercado
    - Potencial de Retorno Financeiro
- Etapa 01: Qualidade do dados
    - Dimensionalidade dos dados
    - Dados faltantes (Missing Values)
- Etapa 02: Análise Descritiva
    - Atributos Numéricos
        - Min, Máximo, Intervalo, Média, mediana, moda, skew, kurtosis
    - Atributos Categóricos
        - Quantidade, Cardinalidade, Moda, Frequência
- Etapa 03: Engenharia de Features
    - Mindmap de hipóteses
    - Lista de Hipóteses
    - Criação de novas features
- Etapa 04: Análise Exploratória de Dados
    - Análise univariada
    - Análise bivariada
    - Análise univariada
- Etapa 05: Feature Selection
    - Seleção por negócio
    - Análise de multicolinearidade
    - Seleção pelo algoritmo Boruta
- Etapa 06: Data Preparation
    - Normalização
    - Rescala
    - Encoders
- Etapa 07: Modelagem ML
    - Algoritmo Baseline
    - Regressão Logística
    - Random Forest, XGBoost e LGBM
- Etapa 08: Hyperparameter Fine Tuning
    - Random Search
    - Bayesian Search
