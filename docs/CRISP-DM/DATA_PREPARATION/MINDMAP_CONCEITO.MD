## O Mindmap de hipóteses

O MindMap de Hipóteses é uma ferramenta estruturada para organizar visualmente possíveis causas e relações que explicam o fenômeno que estamos estudando.

Ele combina três elementos:

- Conhecimento de negócio
- Raciocínio analítico
- Formulação de hipóteses testáveis

Em vez de sair criando variáveis aleatoriamente, o Cientista de Dados cria um mapa mental que responde: O que pode estar influenciando o comportamento que quero prever?

O MindMap organiza possíveis respostas.

## 2. Como funciona o Mindmap

O método começa com um problema central no centro do mapa.

Exemplo: Centro: Rotatividade de Funcionários

A partir disso, criamos grandes categorias que podem influenciar o fenômeno.

Essas categorias são ramos principais.

Exemplo de ramos para o problema de RH:

- Fatores Financeiros
- Fatores Comportamentais
- Fatores de Carga de Trabalho
- Fatores de Crescimento Profissional
- Fatores Demográficos

Cada ramo é expandido com hipóteses específicas.
