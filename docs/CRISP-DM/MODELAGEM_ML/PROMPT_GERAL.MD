PAPEL
Atue como um Cientista de Dados especializado em Algoritmos de Machine Learning com experiência em ensino.

OBJETIVO
Ensinar o funcionamento do algoritmo XGBoost completo.

CONTEXTO
Estou estudando Machine Learning e quero entender o funcionamento do algoritmo XGBoost.
O minha é em Engenharia. Eu entendo algumas ferramentas matemáticas, mas não tenho pleno domínio como um Matemático, Físico ou Estatístico, por exemplo.

Eu uso o seguinte processo com 4 etapas para aprender o funcionamento dos algoritmos de Machine Learning:

Etapa 1: Funcionamento Geral
Nessa etapa, o meu principal interesse é entender 1) O tipo de aprendizado do algoritmo, 2) As entradas que ele recebe e as 3) Saídas que ele fornece.
A idéia é ter uma visão bem geral do que o algoritmo faz.

Etapa 2: Processo de Aprendizado
Na segunda etapa, o objetivo principal é entender o processo de aprendizado do algoritmo. O passo a passo usado pelo algoritmo para aprender a apartir de uma base de dados.
Nessa etapa, eu não me preocupo com fórmula e nem métodos, apenas o entendimento do passo a passo do algoritmos, como um processo sequencial de etapas.

Etapa3: Ferramentas e Métodos de cada etapa
Nessa fase, o meu principal objetivo é entender como as etapas são realizadas. Quais ferramentas ou métodos matemáticos ou estatísticos são utilizados. Ainda sem me preocupar com fórmulas, mas com a função daquela ferramentas. Por exemplo, o gradiente descendente é um método de otimização que busca encontrar os parâmetros que minimizam uma função. Em outras palavras, eu busco entender o motivo daquele método ou ferramenta atuar naquela etapa do algoritmo de aprendizado.

Etapa 4: Funcionamento matemático.
Nessa etapa, o objetivo principal é entender as ferramentas e métodos do ponto de vista matemático, olhando para as fórmulas, restrições, limites de atuação da ferramenta matemática.

A melhor forma de aprendizado é de maneira prática, com base de dados simples, que podem ser usados para ilustrar cada uma das etapa de forma iterativa. Ou seja, uma etapa de cada vez, pausadamente, com uma validação de entendimento da etapa antes de seguir para a próxima.

TAREFA
A sua tarefa é explicar o funcionamento do algoritmo XGBoost usando as 4 etapas do processo descrito acima de forma iterativa usando um problema simples de classificação binária, ou seja, a explicação de uma etapa, a validação do conhecimento antes de avançar para a próxima etapa.

RESULTADO
